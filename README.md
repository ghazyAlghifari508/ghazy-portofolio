# Ghazy Nabil Alghifari — Personal Portfolio

Personal portfolio website built with [Astro v5](https://astro.build) and [Tailwind CSS v4](https://tailwindcss.com). Showcases selected works across full-stack applications, AI SaaS products, interactive web tools, and educational ecosystems.

## ✨ Tech Stack

- **Framework:** [Astro 5](https://astro.build) (Content Collections, Server-Driven Islands)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com)
- **Typography:** Cabinet Grotesk
- **Data & Content:** JSON-based Astro Content Collections with Zod validation
- **Image Optimization:** Sharp / WebP
